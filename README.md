### Prompt Optimizer

**核心提炼**
- 解决什么问题：手写的 prompt 又糙又玄，AI 输出质量不稳定——缺一个把想法打磨成好 prompt 的工具。
- 核心用法（5 步）：1) 打开在线版 prompt.always200.com，或装桌面版 / Chrome 插件 / Docker 自部署；2) 粘贴自己写的 prompt，选模型（OpenAI / Gemini / DeepSeek / Grok 等）；3) 一键优化，多轮迭代打磨；4) 用分析 / 对比评测看是不是真的变好了；5) 存成可复用的 prompt 资产。还有图像生成模式（文生图 / 图生图，支持 Seedream / Gemini），做视频前可先出关键帧。
- 什么时候用 / 常见坑：任何模型出片翻车，先拿它"审一遍 prompt"；纯客户端直连 AI 服务商、数据不经过中间服务器，API key 需要自己配。

**适用场景**：所有写 prompt 的人、做 prompt 咨询或教学的人。

**怎么用它搞钱**：提示词优化服务 / 教学 / 卖 prompt 资产包。

### PromptEnhancer

**核心提炼**
- 解决什么问题：英文 prompt 写得太糙，生图模型"听不懂"、出图偏离意图——需要一个改写器把 prompt 重构成模型好理解的结构。
- 核心用法（4 步）：1) `pip install -r requirements.txt` 装好环境；2) 从 Hugging Face 下载 PromptEnhancer-7B（13GB，质量和效率最均衡）；3) 输入原始 prompt，模型做思维链改写——保留原意，输出结构化增强版；4) 拿增强后的 prompt 去生图或做图生图编辑。
- 什么时候用 / 常见坑：做视频分镜图 / 关键帧之前先过一遍增强器；官方是腾讯混元团队的 CVPR 2026 项目，偏研究向，跑 7B / 32B 模型需要 GPU。

**适用场景**：做 AI 视频分镜 / 关键帧的创作者、技术向 prompt 玩家。

**怎么用它搞钱**：分镜 / 关键帧代做服务 / 技术教学。

### 真实视频提示词 skill

**适用场景**：做真实感 / UGC 风 AI 视频的创作者、想给视频去 AI 味的人。

### Vibe Creating

**核心提炼**
- 解决什么问题：堆参数写分镜式提示词，模型越强越没必要——真正值钱的是"讲好故事"，让模型自己找镜头和节奏。
- 核心用法（4 步）：1) 按 Agent Skill 标准装（Claude Code / Codex / OpenClaw / Hermes），或当中英双语规则用；2) 输入粗糙想法 / 情绪 / 过度指定的分镜；3) skill 先判断：场景 × 表达 × 信息三轴打分，不合适就原样保留、信息不够先问 1–3 个短问题；4) 输出固定四段式：判断 → 动作（直通 / 轻清理 / 重写 / 追问）→ 结果 → 备注。可跑 Seedance 2.0 / Kling / Veo / Hailuo / Wan / Vidu 等（可走 Atlas Cloud 统一 API）。
- 什么时候用 / 常见坑：想法是情绪 / 故事而不是分镜时用；精确分镜需求它会主动让路、不扁平化——这就是它跟"缩短器"的本质区别。方法论源自 ByteDance 的 Vibe Creating。

**适用场景**：想用"故事感"驱动出片的创作者、跨模型用户。

**怎么用它搞钱**：创意型商单 / 教学（ByteDance 方法论是差异化卖点）。

**来源**：[Alisa0808/vibe-creating-skill](https://github.com/Alisa0808/vibe-creating-skill) · ⭐162 · 更新于 2026-11-11

### FPV 运镜导演 skill

**核心提炼**
- 解决什么问题：FPV 视频提示词只写"画面描述"，镜头不知道从哪来、经过谁、停在哪——缺"行动轨迹设计"。
- 核心用法（3 步）：1) 按 Agent Skill 标准安装（Hermes / Claude / Codex / Cursor）；2) 输入一句话需求（如"咖啡厅里 3 个人依次互动的 FPV，15 秒，猫咪视角"）；3) skill 先判断是不是红线路径场景，再输出完整资产包：带编号停靠点的首帧图 + 独立人物参考图 + 按顺序经过各停靠点、绕过障碍、最后停点的轨迹提示词，而不是只给一张首帧。

**适用场景**：做 FPV / 穿越 / 第一人称沉浸视频的人。

**怎么用它搞钱**：FPV 商单 / 沉浸式广告代做。

### 人物表演与视频提示词导演 Skill

**核心提炼**
- 解决什么问题："她很伤心"式提示词等于没写——人物表演缺动机、缺递进、缺微表情，出来的全是瞪眼式演技。
- 核心用法（3 步）：1) 按 Agent Skill 标准安装；2) 输入一句模糊描述（如"现代职场女性看到暗恋同事走过来"）；3) skill 先建表演动机（触发事件 / 当前目标 / 现实障碍 / 保护策略 / 隐藏潜台词），再把情绪拆成眼神、眼睑、眉间、嘴角、下颌、呼吸、姿态、声音的连续变化，并补全成年角色、场景、戏剧动机、镜头、光线、声音、准确时长和负面约束，输出可直接复制的完整提示词。
- 什么时候用 / 常见坑：文戏 / 对白 / 情绪转折镜头必用；先有动机再有表情，顺序别反。

**适用场景**：做 AI 短剧 / 文戏 / 人物特写的人。

**怎么用它搞钱**：短剧商单 / 表演指导式提示词教学。

### @m4lkxx Opus 5.5 代码视频缺陷检查法：视频不差，差的是检查（8 级检查阶梯）

- 干货要点：1) 核心结论：运镜是为情绪服务的；写运镜前先问三问：这一镜想让观众看清什么（环境、人、细节）？观众这时候应该是什么情绪（平静、紧张、好奇、被震撼）？镜头动完之后停在哪里？硬规矩：一条 5–10 秒的 AI 视频只给一种运镜，推着又摇着又环绕，模型很容易糊掉、画面也会抖；2) 9 种运镜（每种含一句可直接抄的中文提示词）：固定镜头（机位完全不动、只有画面里的人和物在动，对话、人物表演、产品静物展示，新手最该多用；一定要写"镜头完全不动"或"固定机位"，只写"静态画面"有些工具会理解成照片、人也不动了；例：固定机位，镜头完全不动，中景，一位老奶奶坐在老街门口的竹椅上剥毛豆，阳光从左侧照进来，画面安静，只有她的手在动）；推镜（镜头朝主体慢慢往前走，人越来越大，人物想通一件事、突然紧张、要说关键台词，或产品片从整体推到卖点细节；例：镜头从中景缓慢推近到面部特写，一个年轻男生站在雨夜的公交站台，听到手机里的消息后愣住，眼神慢慢变得湿润，推进速度平稳不晃动）；拉镜（镜头往后退、主体越来越小、环境越露越多，片尾收场、表现孤独渺小、揭示"原来他在这么大的地方"；例：镜头从女孩的背影近景缓慢向后拉远，逐渐露出她独自站在一望无际的盐湖中央，天空倒映在水面上，画面越来越空旷，结尾停在大远景）；摇镜（机位不动、镜头转头，左右叫横摇、上下叫竖摇，从一个人看向另一个人交代关系，或从脚往上摇到脸制造"这个人出场了"；想要摇镜就强调"机位固定、镜头转动"，摇镜和横移很容易被模型混淆；例：机位固定，镜头从左向右缓慢横摇，先看到窗边看书的女孩，再摇到门口刚进来的男孩，两人对视，室内暖色灯光）；横移（整台摄影机沿一条线平着移动、方向和画面平行，展示一排东西或和走路的人保持平行；例：镜头从左向右平行横移，经过一排傍晚亮着暖灯的老街小吃摊，蒸汽从锅里冒出来，行人在前景走过，移动速度均匀）；跟拍（镜头跟着运动的人物一起移动、人物在画面里位置基本不变，可从背后跟、也可从正面倒着走着拍，人物在走在跑在追、想让观众代入视角，短剧和 vlog 常用；例：镜头从背后跟拍，保持中景距离，一个背着书包的女生快步穿过清晨的校园林荫道，阳光透过树叶洒在她身上，镜头平稳跟随不抖动）；升降（镜头垂直向上升起或往下降，开场交代城市或场地、结尾升高收尾，或从高处降下来落到主角身上；例：镜头从地面上的男孩身上缓缓升起，越升越高，变成俯瞰视角，露出他站在一片金黄的稻田中间，远处是连绵的山，傍晚暖光）；环绕（镜头围着主体画弧线或转圈、主体一直在画面中间，主角高光时刻、产品全方位展示、两个人第一次对视，一条片子用一次就够；建议写"环绕半圈"或"环绕 90 度"，比"360 度环绕"更稳，转满一圈人物背面和脸部更容易变形；例：镜头围绕主角缓慢环绕半圈，一位穿红色长裙的女生站在天台上，城市夜景灯光在背景里虚化，风吹起她的头发，环绕速度缓慢平稳）；手持和希区柯克变焦（手持：模拟人拿摄影机、带一点轻微晃动，临场感纪录感，街头、紧张追逐、生活化 vlog；希区柯克变焦：镜头一边往前推、一边把画面视野拉宽，人物大小基本不变、背景像往后缩往外扩，"世界突然变了"的眩晕感，人物震惊、恍然大悟的瞬间；做不出来别硬磕，换成"缓慢推近到特写"，情绪一样能到）；3) 万能顺序：先写运镜（镜头怎么动、从哪到哪、速度快慢）→ 再写景别（从中景到特写，还是从近景到大远景）→ 然后写主体和动作（谁、在干什么）→ 最后写环境、光线和稳定性（在哪里、什么光、镜头平稳不抖动）；运镜放最前面（不少工具对开头的词更敏感），速度一定要写，"缓慢""平稳""匀速"能帮你少抽很多废片；完整示例：镜头缓慢推近，从全景推到人物近景，一位戴围裙的面包师傅从烤箱里端出一盘刚烤好的牛角包，热气升起，清晨暖黄色侧光，镜头平稳不抖动，电影质感；4) 4 个坑：一条片子堆好几种运镜（推、摇、环绕全写上，模型只能乱拼、画面就抖，一条只给一种）；只写"镜头移动"不写方向（往哪动、从哪到哪一定要说清楚）；不写速度（不写的话有的工具会给你一个很冲的快推，廉价感立刻出来）；人物动作和运镜方向打架（人往左跑、镜头往右横移，画面很别扭，让镜头顺着人物的方向走）。

### @swordBluesy 首尾帧插值：两张照片长出一段视频

**核心提炼**
- 解决什么问题：单张照片动起来不难，难的是让视频"到得了你指定的结尾"——给一张图叫模型自由发挥，它永远到不了你要的收尾画面，产品片结尾没有商标特写、解说片结尾没有对照画面，整段就白做了。
- 干货要点：1) 方法定义：首尾帧条件（start-and-end frame conditioning），又称关键帧插值——上传开头、结尾两张静照，写一段中间运镜提示词，模型负责把中间的帧补出来；中间帧是算出来的，不是拍出来的；2) 代价与适用条件：这招只在两张图本来就长得像的时候才成立，两张图毫无共同点，再好的模型也只能让主体溶进背景里；只想让一张照片动起来、没有指定结尾，那是单图生成的活，不必绕进双图插值；两张图光线、色温、相机高度差太多，中间帧补不出连续路径，先把两张图拉近再回来；5 秒片段里想堆三种运镜（orbit then crane then whip pan）只会让模型每一种都做一半，5 秒内只用一个运镜动词；适用场景：开头干净主角镜头、结尾商标安全广角的产品广告，或 before 到 after 的解说，或首尾接回同一画面的循环片段；3) 提示词写法：只写镜头怎么动、真正要变的东西是什么，不写故事、不写剧情；范例：Slow push-in toward the ceramic mug on the table, mug stays still and unchanged, soft window light, end on the wider product shot.（镜头慢慢推向桌上的陶瓷杯，杯子保持静止不变，柔和窗光，最后停在更宽的产品镜头）；4) 翻车清单：两张图毫无共同点还硬做；提示词写成短故事；5 秒堆三种运镜；两张图光线色温差太多；标签与人脸在两张图里不清楚（背景太乱、标签模糊，模型中途会把标签文本吃掉）；只用正常速度验收（主体撑到最后半秒才突然跳进结尾帧，正常速度根本看不出来）；假设每个文生视频框都支持（按 start frame、end frame、keyframes 查接口标签）；5) 三条路对比：单图生成 + 剪辑溶解（任何单图工具都能做，但不是真插值、中间没有连续路径）；自由生成 + 后期裁切（快，但结尾是粘贴去的、不是长出来的）；首尾帧插值（中间有连续路径、结尾是算出来的，缺点是两张图必须长得像、工具要支持首尾帧条件）；结尾不是装饰、是验收标准，只有第三条路把结尾写进生成条件；6) 迁移步骤（10 步 condensed）：挑对场景 → 备两张图（共用光线、色温、大致相同相机高度，主体比例相近，背景简洁，标签与人脸两张图都清晰）→ 加一张侧面参考图（减少瓶盖这类小对象变形）→ 写提示词（只写镜头 + 真正要变的东西）→ 一个片段一个运镜动词 → 确认工具支持（Kling 4.0 家族文档载明关键帧控制与 Omni 式参考堆栈，Luma Dream Machine、Runway 早有首尾帧条件，Google Gemini Omni 系列亦提第一帧与最后一帧生成、有时长限制）→ 工具不支持时退回 dissolve 接法 → 验收先正常速度播一次、再逐帧检查中段与结尾附近 → 抓三种毛病（最后半秒跳帧、裁切漂移/色偏/标签文本缺失、中段融化就缩短时长、拉近两图角度与光线、把提示词砍到一个镜头动词）→ 收尾进剪辑软件（修掉头尾发软的帧、自己加字幕，产品片结尾仍微瑕直接以真实产品照片作结尾）；7) 自查三问：两张图长得像吗、提示词只剩一个运镜动词吗、逐帧检查过结尾附近吗。
